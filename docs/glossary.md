# Glossary

- **Source text:** The string pasted into the input area, possibly with rich-text formatting or Markdown syntax.
- **Corrected text:** The spelling-corrected version shown next to the source for review before copying.
- **Spelling-only edit:** A change to a misspelled word or its accents. Grammar and punctuation remain as written, as part of the user's tone.
- **Formatting:** Line breaks and whitespace, plus supported rich-text attributes or Markdown syntax. Copied Markdown is rendered as rich text by default.
- **Floating window:** A window that stays separate from AeroSpace's tiled layout; exact focus and workspace behavior need confirmation on the user's setup.
- **Automatic model:** The fastest currently available model in the app's multilingual shortlist, according to OpenRouter's recent median latency ranking. The user can override it.
